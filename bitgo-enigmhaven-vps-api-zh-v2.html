enigmhaven VPS API

使用 bitgo 消费 enigmhaven VPS

bitgo 除了支持大模型 token 消费，也可将 VPS 的创建、查询、启停与删除等服务调用纳入同一套可审计的支付授权链路。本文档覆盖 VPS 规格、SSH Key 与 VPS 实例的全部 API。

只有 GET /vps/v1/resources 免签。其余接口均复用大模型推理 API 的两层签名认证：钱包业务签名 + 接口级 ECDSA 签名。

VPS 规格 API

先查询可用资源，获取后续创建实例所需的 zoneId、instanceTypeId 与 imageId。这是唯一无需钱包授权与接口级 ECDSA 签名的 VPS 接口。

项目值说明
Endpointhttps://api-bitgo.enigmhaven.com/vps/v1/resources查询可用区域、实例规格与镜像
MethodGET无需认证 Header
Content-Type—无请求体

调用示例

curl "https://api-bitgo.enigmhaven.com/vps/v1/resources"

返回结构

zones[zoneId]
├── zone
└── instanceTypes[instanceTypeId]
    ├── instanceType
    └── images[]
区域从 zones 中选择可用的 zoneId。
规格实例规格通常包含 CPU、内存、磁盘、带宽、库存、网络计费类型、月价、时价和流量字段。
镜像从选定规格的 images[] 中读取 imageId。
价格字段价格与流量字段在服务定义中为字符串；客户端应保留原始值并结合服务端说明展示。

推荐流程：先调用本接口确认真实可售资源，再创建 SSH Key 与 VPS。不要猜测、硬编码或复用过期的区域、规格或镜像 ID。

SSH Key API

SSH Key API 用于查询和创建 SSH 公钥。除资源规格接口外，所有 VPS API 都携带以下四个运行时生成的 Header；这套认证逻辑与大模型推理 API 完全一致。

Header占位值说明
X-ParamsBASE64_ENCODED_WALLET_PARAMS钱包业务签名参数的整体 Base64 编码
X-NonceRANDOM_NONCE每次请求重新生成的随机字符串
X-SignatureECDSA_SIGNATURE_HEX对 SHA-256(X-Params + X-Nonce) 的 ASN.1/DER 签名并 HEX 编码
X-Public-KeyECDSA_PUBLIC_KEY用于服务端验签的本地 ECDSA 公钥

钱包业务签名消息严格为 wallet_address + money + money_id；将包含 wallet_address、money、money_id 与钱包签名的 JSON 整体 Base64 编码，得到 X-Params。接口级密钥对需稳定保存，每个请求只重新生成 nonce 和接口签名。

真实私钥、完整钱包签名、完整 X-Params、X-Signature、X-Public-Key 或管理 token 均不得写入源码、仓库、日志或本文档。以下内容仅使用不可用的占位符。

查询 SSH Key

项目值
EndpointGET /vps/v1/ssh-keys
认证两层签名认证
响应sshKeys[]，包含 sshKeyId、displayName、description、publicKey、createdAt、updatedAt
curl "https://api-bitgo.enigmhaven.com/vps/v1/ssh-keys" \
  -H "X-Params: BASE64_ENCODED_WALLET_PARAMS" \
  -H "X-Nonce: RANDOM_NONCE" \
  -H "X-Signature: ECDSA_SIGNATURE_HEX" \
  -H "X-Public-Key: ECDSA_PUBLIC_KEY"

创建 SSH Key

字段类型必填说明
displayNamestring是显示名称
descriptionstring是描述
publicKeystring是OpenSSH 格式公钥
curl -X POST "https://api-bitgo.enigmhaven.com/vps/v1/ssh-keys" \
  -H "Content-Type: application/json" \
  -H "X-Params: BASE64_ENCODED_WALLET_PARAMS" \
  -H "X-Nonce: RANDOM_NONCE" \
  -H "X-Signature: ECDSA_SIGNATURE_HEX" \
  -H "X-Public-Key: ECDSA_PUBLIC_KEY" \
  -d '{
    "displayName": "dev-key",
    "description": "Development SSH key",
    "publicKey": "ssh-ed25519 PUBLIC_KEY_MATERIAL user@example.com"
  }'
{
  "sshKey": {
    "sshKeyId": "SSH_KEY_ID",
    "displayName": "dev-key",
    "description": "Development SSH key",
    "publicKey": "ssh-ed25519 PUBLIC_KEY_MATERIAL user@example.com",
    "createdAt": "2026-07-16T08:00:00Z",
    "updatedAt": "2026-07-16T08:00:00Z"
  }
}

只提交 SSH 公钥。SSH 私钥由持有人自行安全保管，不得提交到 Git 或用于构造 bitgo 认证材料。

VPS API

VPS API 用于分页查询、创建、查询单实例、启动、停止和删除实例。全部接口复用两层签名认证；创建、启停和删除属于有状态操作，应由人确认目标和影响后执行。

接口总览

方法路径说明
GET/vps/v1/vps分页查询 VPS 实例
POST/vps/v1/vps创建 VPS 实例
GET/vps/v1/vps/{instanceId}查询单个 VPS 实例
POST/vps/v1/vps/{instanceId}/start启动 VPS
POST/vps/v1/vps/{instanceId}/stop停止 VPS
DELETE/vps/v1/vps/{instanceId}删除 VPS

查询 VPS 列表

可按页码、每页数量和实例状态过滤。服务文档约定默认每页 20 条，最大 100 条。

参数类型必填说明
pageSizeint32否每页数量
pageNumberint32否页码，从 1 开始
statusstring否按实例状态过滤
curl "https://api-bitgo.enigmhaven.com/vps/v1/vps?pageSize=20&pageNumber=1&status=InstanceStatusRunning" \
  -H "X-Params: BASE64_ENCODED_WALLET_PARAMS" \
  -H "X-Nonce: RANDOM_NONCE" \
  -H "X-Signature: ECDSA_SIGNATURE_HEX" \
  -H "X-Public-Key: ECDSA_PUBLIC_KEY"

响应包含 instances、total、pageSize 和 pageNumber。

创建 VPS

字段类型必填说明
displayNamestring是实例显示名称
zoneIdstring是资源接口返回的区域 ID
instanceTypeIdstring是资源接口返回的规格 ID
imageIdstring是资源接口返回的镜像 ID
sshKeystring否SSH Key；服务定义未明确为 Key ID 或公钥内容，调用前以服务端约定为准
passwordstring否登录密码
commandstring否实例初始化命令
curl -X POST "https://api-bitgo.enigmhaven.com/vps/v1/vps" \
  -H "Content-Type: application/json" \
  -H "X-Params: BASE64_ENCODED_WALLET_PARAMS" \
  -H "X-Nonce: RANDOM_NONCE" \
  -H "X-Signature: ECDSA_SIGNATURE_HEX" \
  -H "X-Public-Key: ECDSA_PUBLIC_KEY" \
  -d '{
    "displayName": "dev-vps-01",
    "zoneId": "ZONE_ID",
    "instanceTypeId": "INSTANCE_TYPE_ID",
    "imageId": "IMAGE_ID",
    "sshKey": "SSH_KEY_ID",
    "command": "echo ready"
  }'
{ "instanceId": "INSTANCE_ID" }

查询单个 VPS

GET /vps/v1/vps/{instanceId} 返回 instance 对象，主要包含实例标识和名称、区域、规格、CPU、内存、镜像、状态、创建与过期时间、公私网 IP、网卡、系统盘与数据盘，以及 keyId、moneyId、publicKey 等关联信息。

curl "https://api-bitgo.enigmhaven.com/vps/v1/vps/INSTANCE_ID" \
  -H "X-Params: BASE64_ENCODED_WALLET_PARAMS" \
  -H "X-Nonce: RANDOM_NONCE" \
  -H "X-Signature: ECDSA_SIGNATURE_HEX" \
  -H "X-Public-Key: ECDSA_PUBLIC_KEY"

启动 VPS

POST /vps/v1/vps/{instanceId}/start 的请求体为必填空 JSON 对象，成功时返回 HTTP 200 与空 JSON 对象。

curl -X POST "https://api-bitgo.enigmhaven.com/vps/v1/vps/INSTANCE_ID/start" \
  -H "Content-Type: application/json" \
  -H "X-Params: BASE64_ENCODED_WALLET_PARAMS" \
  -H "X-Nonce: RANDOM_NONCE" \
  -H "X-Signature: ECDSA_SIGNATURE_HEX" \
  -H "X-Public-Key: ECDSA_PUBLIC_KEY" \
  -d '{}'

停止 VPS

POST /vps/v1/vps/{instanceId}/stop 支持可选布尔字段 force；默认正常关机。

curl -X POST "https://api-bitgo.enigmhaven.com/vps/v1/vps/INSTANCE_ID/stop" \
  -H "Content-Type: application/json" \
  -H "X-Params: BASE64_ENCODED_WALLET_PARAMS" \
  -H "X-Nonce: RANDOM_NONCE" \
  -H "X-Signature: ECDSA_SIGNATURE_HEX" \
  -H "X-Public-Key: ECDSA_PUBLIC_KEY" \
  -d '{"force": false}'

强制关机使用 {"force": true}，可能导致未保存数据丢失；仅在正常关机失败时使用。

删除 VPS

DELETE /vps/v1/vps/{instanceId} 成功时返回 HTTP 200 与空 JSON 对象。

curl -X DELETE "https://api-bitgo.enigmhaven.com/vps/v1/vps/INSTANCE_ID" \
  -H "X-Params: BASE64_ENCODED_WALLET_PARAMS" \
  -H "X-Nonce: RANDOM_NONCE" \
  -H "X-Signature: ECDSA_SIGNATURE_HEX" \
  -H "X-Public-Key: ECDSA_PUBLIC_KEY"

删除通常不可逆。调用前核对 instanceId，确认实例内数据已备份，并获得明确授权。

查询实例计费汇总

GET /vps/v1/billings 分页查询 VPS 实例的累计计费记录，支持按实例 ID 筛选。此接口需要携带两层签名认证所需的四个 Header。如需核对最新的 bitgo 零钱包余额及 VPS 消费明细，可通过查询 bitgo 零钱包信息和查询 bitgo 零钱包消费记录接口获取。

参数类型必填说明
pageSizeint64否每页记录数
pageNumint64否页码
instanceIdstring否按 VPS 实例 ID 筛选
curl "https://api-bitgo.enigmhaven.com/vps/v1/billings?pageSize=20&pageNum=1&instanceId=INSTANCE_ID" \
  -H "X-Params: BASE64_ENCODED_WALLET_PARAMS" \
  -H "X-Nonce: RANDOM_NONCE" \
  -H "X-Signature: ECDSA_SIGNATURE_HEX" \
  -H "X-Public-Key: ECDSA_PUBLIC_KEY"

响应字段

字段类型说明
instanceBillingarray实例计费汇总记录列表
instanceBilling[].iduint64（字符串）计费记录主键
instanceBilling[].createdAtstring记录创建时间
instanceBilling[].instanceIdstringVPS 实例 ID
instanceBilling[].instanceNamestringVPS 实例名称
instanceBilling[].useridstring所属用户 ID
instanceBilling[].chargestring累计费用，以 decimal 字符串表示
totalCountint64符合筛选条件的总记录数
{
  "instanceBilling": [
    {
      "id": "1",
      "createdAt": "2026-07-23T08:00:00Z",
      "instanceId": "instance-id",
      "instanceName": "dev-vps-01",
      "userid": "user-id",
      "charge": "0.01488"
    }
  ],
  "totalCount": 1
}

推荐调用流程

  1. 查询可用 VPS 资源，确认 zoneId、instanceTypeId 和 imageId。
  2. 按两层签名认证查询或创建 SSH Key。
  3. 按两层签名认证创建 VPS，并保存返回的 instanceId。
  4. 轮询单实例查询接口，直到实例进入可用状态；不要仅以创建请求返回 200 判断已可用。
  5. 按明确授权启动、停止或删除实例。

错误处理与审计

  • 服务定义仅声明成功响应 200，客户端必须检查实际 HTTP 状态码，不要假设所有响应都成功。
  • 对网络超时、TLS 错误和 5xx 实现有限次数退避重试；对创建、启停、删除等写操作谨慎重试，避免重复执行。
  • 日志可以保留请求时间、路径、状态码和脱敏后的服务端错误信息；不要记录密码、私钥或完整认证 Header。
  • 如开发环境证书无法被本机信任，可临时使用 curl -k 排查连通性；生产环境必须配置并校验有效证书。
